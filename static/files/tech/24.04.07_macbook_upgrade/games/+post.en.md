All games were launched from an external Samsung 990 SSD in a Ugreen enclosure over a 10 Gbit/s connection, using compatibility mode for Windows applications with Whisky + GPTK.

Some games I tested on the old MacBook in native mode, but the new one—only in compatibility mode.

I also wanted to test EA racing games, but their launcher refused to run under Whisky, so I dropped that idea.
