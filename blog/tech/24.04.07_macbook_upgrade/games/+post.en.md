All games were run from an external Samsung 990 SSD in a 10Gbps Ugreen pocket, in Windows compatibility mode - Whisky + GPTK.

Some games I tested on the old macbook in native mode, but the new one is already purely in compatibility mode.

I also wanted to test EA races, but since their launcher won't run under Whisky, I gave up.
