Через обмеження MacOS, під потреби GPU виділяється не більше ніж 75% об'єднаної пам'яті, тож для виправлення є невелика команда для терміналу:

```sh
sudo sysctl iogpu.wired_limit_mb=<INT_OF_MEGABYTES>
```
