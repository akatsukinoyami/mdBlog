# Дневники Кацу - Современный движок блога

Современный, быстрый и легкий движок блога, построенный на **SvelteKit 5**, **Tailwind CSS 4** и **TypeScript**. Поддерживает многоязычность, темную/светлую темы, режим экономии трафика и элегантную обработку Markdown.

## 🚀 Возможности

- **Современный стек**: SvelteKit 5 с TypeScript и Tailwind CSS 4
- **Многоязычность**: Поддержка английского, русского и украинского языков
- **Система тем**: Темная/светлая темы с отдельными темами для блоков кода
- **Экономия трафика**: Оптимизированная загрузка изображений с сжатием WebP
- **Markdown-первый**: Расширенный Markdown с пользовательскими расширениями синтаксиса
- **Адаптивный дизайн**: Mobile-first адаптивная верстка
- **Модальные изображения**: Полноэкранный просмотр изображений с навигацией клавиатурой
- **Статическая генерация**: Оптимизирован для развертывания как статический сайт
- **Docker готов**: Контейнерное развертывание с Nginx

## 🛠️ Установка и настройка

### Требования

- **Bun** (рекомендуется) или Node.js 18+
- **Docker** (для контейнерного развертывания)

### Настройка разработки

1. **Клонирование и установка зависимостей:**

```bash
  git clone <repository>
  cd mdBlog
  bun install
```

1. **Запуск сервера разработки:**

```bash
  bun run dev
```

1. **Доступ к приложению:**
   - Разработка: `http://localhost:5173`
   - Предпросмотр продакшена: `bun run preview`

### Сборка для продакшена

```bash
  # Полная сборка для продакшена с оптимизациями
  bun bake

  # Или пошагово:
  bun posts          # Генерация дерева контента
  bun compress:images # Оптимизация изображений
  bun build          # Сборка статического сайта
  bun compress:text   # Сжатие ресурсов
```

## 📝 Управление контентом

### Структура директорий

Контент организован в директории `static/files/` со следующей структурой:

```txt
  static/files/
  ├── index.yaml          # Корневая конфигурация
  ├── category1/
  │   ├── index.yaml      # Метаданные категории
  │   ├── +post.en.md     # Английский контент поста
  │   ├── +post.ru.md     # Русский контент поста
  │   ├── +images/        # Оригинальные изображения
  │   ├── +imagesCompressed/ # Автоматически сгенерированные WebP изображения
  │   └── subcategory/
  │       ├── index.yaml
  │       └── +post.default.md
```

### Файлы конфигурации (index.yaml)

Каждая директория может содержать файл `index.yaml` с метаданными:

```yaml
title:
  en: Category Title
  ru: Название категории
  ua: Назва категорії
post: # Доступные языки
  - en
  - ru
  - default
date: 2025-01-01
```

### Markdown посты

Файлы постов следуют соглашению именования `+post.[язык].md`:

- `+post.en.md` - Английский контент
- `+post.ru.md` - Русский контент
- `+post.default.md` - Резервный контент

## ✨ Расширенный синтаксис Markdown

Блог поддерживает стандартный Markdown плюс пользовательские расширения:

### Сеточные макеты

```markdown
%%%3
Контент в сетке из 3 колонок
%&23
Контент, занимающий 2 колонки внутри родителя с 3 колонками
&%
%%%
```

### Изображения с поддержкой сетки

```markdown
![Подпись](image.jpg) # Стандартное изображение с подписью
!c2[Подпись](image.jpg) # Занимает 2 колонки
!r3[Подпись](image.jpg) # Занимает 3 строки
```

### Встроенный контент

```markdown
@{some-class}[Title](https://example.com)
@{h-150}[Video](https://youtube.com/embed/id)
```

### Специальные эффекты

```markdown
––Скрытый текст–– # Наведите для раскрытия
```

## 🎨 Темы и кастомизация

### Конфигурация тем

Приложение поддерживает множественные комбинации тем:

- **Тема UI**: Светлый/темный режим для интерфейса
- **Тема кода**: Независимая тема для блоков кода
- **Язык**: Английский/русский/украинский интерфейс

### Конфигурация Tailwind

Пользовательские классы Tailwind и safelist определены в `tailwind.config.ts`. Проект использует Tailwind CSS 4 с:

- Пользовательской цветовой палитрой (на основе amber/gray)
- Адаптивной системой сетки
- Утилитами типографики
- Классами анимации

### Добавление новых языков

1. Создайте новый файл перевода в `src/lib/i18n/[язык].ts`
2. Добавьте язык в `src/lib/constants.ts`
3. Обновите определения типов в `src/lib/types.ts`
4. Запустите валидацию локалей: `bun run check:18n`

## 🐳 Развертывание

### Развертывание Docker

Сборка и запуск с Docker Compose:

```bash
  docker-compose up --build
```

Приложение будет доступно по адресу `http://localhost:5173`

### Развертывание CapRover

Для развертывания CapRover:

```bash
  bun run caprover:build  # Сборка и упаковка
  # Загрузите blog.tar.gz в CapRover
```

### Статический хостинг

После выполнения `bun run bake`, разверните директорию `build/` на любом сервисе статического хостинга:

- Netlify
- Vercel
- GitHub Pages
- AWS S3 + CloudFront

- `bun preview` - Предпросмотр продакшен сборки

### Утилитарные скрипты

- `bun check:18n` - Валидация полноты переводов

## 🔧 Конфигурация

### Переменные окружения

Переменные окружения не требуются для базовой работы. Вся конфигурация выполняется через:

- `src/lib/constants.ts` - Константы приложения
- `tailwind.config.ts` - Конфигурация стилей
- `svelte.config.js` - Конфигурация SvelteKit

### Хранилище браузера

Пользовательские предпочтения хранятся в localStorage:

- `lang` - Язык интерфейса
- `theme` - Предпочтение темы UI
- `codeTheme` - Тема блоков кода
- `trafficEconomy` - Настройка оптимизации изображений

## 🎯 Функции производительности

### Оптимизация изображений

- Автоматическая конвертация в WebP

## 🔍 Устранение неполадок

### Распространенные проблемы

**Ошибки сборки:**

```bash
  # Очистка кеша сборки
  rm -rf .svelte-kit build node_modules
  bun install
```

**Ошибки обработки изображений:**

- Убедитесь, что Sharp правильно установлен: `bun add sharp`
- Проверьте разрешения файлов изображений и форматы

**Ошибки валидации переводов:**

```bash
  bun check:18n  # Показывает отсутствующие/лишние ключи
```

### Режим отладки

Включение отладки SvelteKit:

```bash
  DEBUG=vite:* bun dev
```
